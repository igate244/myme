# MYME 要件（2026年10月 一新）

## 位置づけ
人生を記録して振り返る、自分用のライフログ。「過去を貯める」アプリ。
- 毎日回す習慣・継続 → KEEP（別アプリ）
- 人間関係・人物 → 人間図鑑（別アプリ）

## 画面
| 画面 | 中身 |
|---|---|
| ライフログ | 出来事を年ごとのタイムラインで。タグ（分岐点・家族・仕事・趣味・その他）、検索 |
| 子どもの記録 | 子どもごとの成長記録。年齢（○歳○ヶ月）を自動表示 |
| やりたいこと | 未着手／挑戦中／達成、カテゴリ、期限、チェックリスト |
| 真理図鑑 | 人生で見つけた真理を集めて育てる。一言 or「〇〇とは」、どうやって気づいたか、分野（複数選べる。名前・色・並び・追加・削除を自分で編集。初期は仕事・家族・お金・人間関係・心と体・生き方）、出どころ（自分の経験・人から・本や作品）、見つけた日、きっかけのライフログ。「また実感した」で確かさが育つ。確かさ順／新しい順／年ごと。空の定義は「まだ見つけてない真理」。ホームに「今日の真理」 |
| 名言 | 他人の言葉。誰の言葉・作品。人で絞り込み・検索。真理図鑑とは分けたまま |
| 遺すもの | 宛先ごとの手紙・思い出 |
| 自分 | プロフィール・自己分析、ドライブのバックアップ、ファイル書き出し／読み込み、ログアウト |

## 方針
- スマホ完結で開発・運用（GitHub に push → 自動公開）
- データは端末内（IndexedDB）。バックアップは本人の Google ドライブ（drive.file）
- 見た目は落ち着いたデザイン（ゲーム風はやめた）
- 人物名鑑・カウンターは画面から外したが、データは消さずに残している

- 毎日守れたかのチェックは KEEP に任せる
- 「気持ちから開く」入口は、使われなかったので 2026-10-21 に外した（データは残す）
